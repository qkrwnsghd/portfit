# AI 시대, 왜 메모리 반도체인가? 30초 Motion Effect 제작 계획서

## 1. 기획 요약

- **주제:** AI 시대, 왜 메모리 반도체(HBM)에 주목할까? 반도체 투자 관심자를 위한 30초 설명
- **연결 자료:** 중간고사 과제 「한국 메모리 반도체 투자 전망 보고서」(Hallym Investment, 삼성전자·SK하이닉스 중심)의 핵심 흐름을 30초로 압축
- **대상:** 반도체 산업에 주식투자 관심이 있는 대학생 (반도체 비전공자 포함)
- **목표:** ① AI 연산에서 메모리가 병목이 되는 이유 ② HBM의 구조 ③ 한국 기업의 위치 ④ 메모리 사이클 위험 ⑤ 투자 전 확인할 체크포인트를 순서대로 전달한다.
- **길이:** 정확히 30초 (6개 장면 × 5초)
- **화면:** 16:9 와이드 (1920×1080 기준 설계, 브라우저 크기에 맞춰 비율 유지 축소·확대)
- **스타일:** 어두운 남색 배경 + 청록(데이터·회로) + 금색(성장·핵심 강조). 보고서 표지 이미지(HBM 칩, 금색 데이터 흐름)와 같은 색 체계
- **음성:** 여성 AI 합성 내레이션, HTML 안에 내장해 인터넷 없이 재생. 브라우저 음성(macOS ‘유나’ 등)으로 바꿔 들을 수 있는 선택 버튼 제공
- **자막·스크립트:** 하단에 내레이션 자막(핵심 문장)과 보충 설명을 함께 표시
- **조작:** 장면 선택 6개, 시작, 일시정지, 종료, 재생 위치 막대, 음성 켜기/끄기, 음량, 전체화면

## 2. 설명 원칙

1. **투자 권유가 아니다.** 특정 종목의 매수·매도를 권하지 않고, 산업 구조와 확인할 점을 설명하는 교육용 자료임을 마지막 화면에 표시한다.
2. **검증되지 않은 수치를 넣지 않는다.** 점유율·주가·실적 숫자는 화면에 쓰지 않는다. 그래프는 모두 ‘개념 시각화’로 표시한다.
3. **단정하지 않는다.** “HBM이 성장을 보장한다”가 아니라 “AI 수요가 메모리 대역폭 수요를 키운다”, “사이클 위험이 함께 있다”처럼 성장성과 위험을 같이 말한다.
4. 기업 비교는 공개적으로 널리 알려진 사실 수준(SK하이닉스: HBM 시장 선도 기업으로 평가 / 삼성전자: 대규모 메모리 생산능력을 가진 종합 반도체 기업, HBM 경쟁력 강화 추진)으로 표현하고 우열을 단정하지 않는다.
5. 한 장면에는 한 가지 메시지만 담는다.

|---|---|---|---|---|
| 00–05초 | 01 문제 제기 | 중앙에 GPU 칩이 빛나며 나타나고, 금색 데이터 입자가 칩으로 빨려 들어간다. 제목 ‘AI 붐, 왜 메모리일까?’가 아래에서 올라온다. | AI 붐 속에서, 왜 메모리 반도체가 주목받을까요? | AI 서비스가 커질수록 연산 칩만큼 데이터를 공급하는 메모리의 역할도 커집니다. |

| 15–20초 | 04 한국 기업의 위치 | 지도 핀 대신 두 개의 기업 카드가 좌우에서 들어온다. SK하이닉스 카드에는 ‘HBM 시장 선도 기업으로 평가’, 삼성전자 카드에는 ‘대규모 메모리 생산능력 · HBM 경쟁력 강화 추진’. 가운데에 ‘AI 메모리 경쟁’ 배지. | SK하이닉스와 삼성전자가, 이 경쟁의 중심에 있습니다. | 두 기업은 세계 메모리 시장의 핵심 공급자입니다. 고객사 인증과 차세대 HBM 양산 속도가 경쟁의 관전 포인트입니다. |

## 4. 장면별 제작 지시사항

### 장면 01 · 문제 제기 (0–5초)
- 배경에 은은한 회로 격자와 금색 빛 번짐.
- GPU 칩(사각형 + 핀)이 0.6초 동안 확대되며 등장하고, 금색 입자 12개가 사방에서 칩으로 모인다.
- 상단 라벨: `HALLYM INVESTMENT · 30초 산업 브리핑`

### 장면 02 · 메모리 병목 (5–10초)
- 왼쪽 ‘메모리’ 상자, 오른쪽 ‘GPU’ 상자, 그 사이 좁은 파이프.
- 데이터 블록이 파이프 입구 앞에 3~4개씩 쌓이며 대기한다.
- GPU 위 ‘가동률’ 막대는 낮게 유지(개념 표시, 숫자 없음). ‘메모리 벽’ 라벨은 금색 테두리.

### 장면 03 · HBM 구조 (10–15초)
- D램 층 8개가 0.15초 간격으로 쌓인다.
- 청록 TSV 세로선 6개가 아래에서 위로 빛난다.
- 완성된 HBM이 GPU 옆으로 이동하고, 좁은 파이프가 넓은 버스(여러 줄)로 바뀌며 데이터가 한 번에 흐른다.

### 장면 04 · 한국 기업의 위치 (15–20초)
- 카드 2장이 좌·우에서 들어오고 중앙 배지가 뜬다.
- 숫자(점유율·주가)는 쓰지 않는다. 문구는 2. 설명 원칙 4번을 따른다.

### 장면 05 · 사이클 위험 (20–25초)
- 파동 곡선을 왼쪽에서 오른쪽으로 그린다(선 그리기 모션).
- 곡선의 골짜기 지점에 ‘가격 하락 구간’ 표시.
- 위험 카드 4개가 0.3초 간격으로 나타난다.

### 장면 06 · 투자 체크포인트 (25–30초)
- 체크리스트 4줄이 0.5초 간격으로 체크된다.
- 마지막 문구 ‘성장성 + 사이클 점검’을 크게 표시하고 30초에 정지(자동 반복 없음).
- 하단에 ‘교육용 자료 · 투자 권유 아님 · 개념 시각화’ 표시.

## 5. 플레이어 기능 명세

| 기능 | 동작 |
|---|---|
| 장면 선택 (6개) | 해당 장면 시작 시점(0·5·10·15·20·25초)으로 이동. 재생 중이면 이어서 재생, 정지 중이면 그 장면을 미리보기 |
| 시작 | 현재 위치부터 재생. 30초에 도달해 끝났으면 0초부터 다시 재생 |
| 일시정지 | 현재 위치에서 멈춤 |
| 종료 | 음성과 모션을 멈추고 0초 첫 화면으로 되돌림 |
| 재생 위치 막대 | 드래그해 원하는 시점으로 이동, 음성도 같은 시점으로 맞춤 |
| 음성 켜기/끄기 | 음성을 꺼도 자막·하단 설명은 계속 동기화 |
| 음성 종류 | ‘내장 음성’(HTML에 포함된 AI 합성 음성, 오프라인) / ‘브라우저 음성’(기기의 한국어 음성) 중 선택 |
| 음량 | 0–100% 슬라이더 |
| 전체화면 | 무대와 컨트롤을 전체화면으로 표시 |
| 시간 표시 | `00:00 / 00:30` 형식 |
| 키보드 | Space 재생·일시정지, ← / → 장면 이동, Esc 종료 |

- 모든 화면은 하나의 시간 값 `t`(0~30초)로 계산해 그리므로, 어느 시점으로 이동해도 화면·자막·음성이 서로 어긋나지 않는다.
- 브라우저 자동재생 제한 때문에 사용자가 시작 버튼을 누른 뒤 음성이 재생된다.
- `prefers-reduced-motion` 설정 시 입자·흐름 모션을 줄인다.

## 6. 음성 제작

- 오픈소스 음성 합성 엔진(sherpa-onnx + Mimic3 한국어 KSS 모델, 여성 음성)으로 장면별 문장을 합성했다.
- 영어 약어는 발음이 정확하도록 한글 표기로 입력했다(AI → 에이아이, HBM → 에이치비엠, SK → 에스케이).
- 각 문장은 장면 시작 0.3초 뒤 시작하고 5초 안에 끝난다(최장 4.4초). 6개 구간을 이어 붙여 30초 음성 하나로 만들고 HTML에 Base64로 넣었다.
- 합성 음성은 사람 성우보다 덜 자연스럽다. 그래서 기기의 한국어 음성으로 바꿔 들을 수 있는 버튼을 함께 두었다.
